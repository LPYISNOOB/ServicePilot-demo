## 6. Docker

Docker Desktop Engine 已成功启动，`docker info` 返回 Server 29.6.2。默认 Docker Hub 基础镜像最初被本机失效的
DaoCloud registry mirror 拦截并返回 401。Dockerfile 因此增加可选 `NODE_IMAGE` 和 `PYTHON_IMAGE` build args，
默认值仍是轻量 `node:24-alpine` 与 `python:3.13-slim`。

使用微软官方替代基础镜像执行了完整多阶段构建：

```powershell
docker build `
  --build-arg NODE_IMAGE=mcr.microsoft.com/devcontainers/javascript-node:24-bookworm `
  --build-arg PYTHON_IMAGE=mcr.microsoft.com/devcontainers/python:1-3.13-bookworm `
  --tag servicepilot:mcr-verified D:\ServicePilot
```

结果：React build、Python wheel 构建、运行依赖安装、非 root 用户和最终镜像导出全部成功。替代镜像生成的验证镜像约
2.5 GB，只用于绕过本机代理；正常环境应使用默认 slim/alpine 获得更小镜像。

随后实际运行容器并验证：
